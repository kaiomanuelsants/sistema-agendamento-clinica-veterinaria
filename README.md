# Sistema de Agendamento — Clínica Veterinária

## Descrição do Projeto
Este projeto tem como objetivo o planejamento de um sistema de agendamento para uma clínica veterinária. O sistema permite organizar consultas, cadastro de tutores, pets e serviços oferecidos pela clínica, garantindo melhor controle da agenda e qualidade no atendimento.

## Objetivos do Sistema
- Organizar agendamentos de consultas e serviços
- Cadastrar clientes e seus pets
- Melhorar o controle da agenda
- Evitar conflitos de horários

## Tecnologias Propostas
- Trello — organização do projeto
- GitHub — versionamento e documentação
- dbdiagram — modelagem do banco de dados
- Figma — prototipação das telas
